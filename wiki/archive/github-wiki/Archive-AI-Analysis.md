# AI 日志分析

右侧功能栏的「AI」提供日志分析会话。面板可拖到另一侧、调整宽度或随布局一起恢复；隐藏面板不停止会话，关闭窗口会取消正在运行的分析。

## 配置与使用

1. 点击 AI 侧栏标题中三个点旁的设置图标，打开独立「大模型配置」弹窗，在「模型」页添加配置。填写名称、协议、Base URL、API Key、模型名及最大输出长度。
2. 协议支持 OpenAI 兼容 Chat Completions 和 Anthropic Messages。Base URL 填写 API 根路径，例如以 `/v1` 结束的地址；应用追加对应协议的请求路径。兼容服务必须支持流式响应和工具调用。
3. 保存后执行「测试连接」。测试只发送简短请求，不包含日志，也不开放日志工具。
4. 回到会话，在底部输入分析问题。Enter 发送，Shift+Enter 换行；中文输入法确认候选词不会发送消息。「停止」取消当前分析，达到请求上限后可选择「继续」。

上方通过 MessageScroller 显示流式 Markdown、代码块和表格，用户消息为右侧圆角淡色气泡，引用的日志内容位于气泡上方；AI 内容在左侧直接使用 Markdown 渲染，不带气泡。消息不显示角色标签或常驻复制按钮。正文、引用摘要和思考内容均支持按住鼠标连续拖选、跨段落选择及反向收缩选区；浅深主题的文字选区统一为蓝底白字，正文、引用摘要、思考和代码使用同一选中样式，可右键复制或添加到对话框，并保留日志引用跳转。流式回复逐步更新同一条消息，完成时保留消息身份；只有停留在输出底部时自动跟随，上滚阅读时保持位置，可点击“最新消息”返回底部。下方固定圆角多行输入区，上方输入文字，下方左侧附加所选日志，右侧选择模型、发送、停止或继续，Enter 发送、Shift+Enter 换行，无文字且无附加日志时禁用发送。会话菜单支持新建、切换、删除和加载更多历史。

## 从日志开始分析

在正文或搜索结果中选择日志行，右键选择「添加到 AI 聊天」。面板沿用当前左右侧位置并显示附件的文件名与源行号，可移除单条附件。支持多选，最多 100 行；单次读取最多 48 KiB，长行会截断，消息与附加日志合计最多 64 KiB。附件在后台读取，文件刷新或关闭后需重新选择。只有附件也可发送，默认请求分析异常与依据。

模型实际返回的思考内容在本轮开始时自动展开，在工具调用与回复生成期间保持展开，整轮回复完成或停止后自动折叠；可点击「思考过程」手动收起或再次展开，后续流式增量不覆盖本轮的手动选择；入口、思考正文与工具过程靠左对齐，思考正文使用完整可用宽度。回复和工具返回的日志引用可点击：有有效搜索标签时定位结果行，否则定位源行；结果已过期则提示重新获取。当前会话的早期轮次引用保留版本校验，切换会话或重启后需重新分析以刷新引用。

选中消息文字并右键，可追加到指定文件的搜索框，保留原有输入和搜索选项，不自动执行；如果用户在操作准备期间改写了搜索框，则拒绝覆盖。也可直接要求模型追加搜索文字、标记异常行、高亮关键词或添加文字标记。

## 日志能力

Agent 可以读取当前区域与选择、列出窗口内已打开文件、分页读取源行、搜索当前文件／本窗口文件／发送时已选目录、创建独立 AI 搜索标签、应用本地预定义过滤器、获取结果及取消或清空自己的搜索标签。它也可以设置或取消行标记、添加／更新／删除关键词高亮及文字标记，追加指定文件搜索文字（不执行搜索），并定位源行、指定结果行、首尾或相邻命中。

文件范围在发送时绑定。手动附加未打开的目录结果时，仅额外授权所选文件，不扩展为任意目录访问。之后切换活动文件不会改变“当前文件”搜索目标。返回引用包含文件身份、源行号及版本；关闭、刷新或改变源文件后，旧引用会被拒绝，需要重新获取。目录命中可先跳转打开，再标记或注释。正文、换行与搜索结果共用应用现有的标记、高亮、文字标记和持久化命令。

当前视图、搜索结果和摘要仅返回元数据及源行引用，不带日志正文。搜索默认返回最多 20 条引用，每页最多 40 条、12 KiB；摘要提供每文件计数、行号范围及最多 12 个等距代表行引用，位置样本不代表错误类别。Agent 根据问题读取相关证据，允许在预算内完整读取相关的小结果集，不默认遍历全文。

引用上下文默认读取前后各 3 行、上限各 10 行；定向源行读取默认 10 行，最多 100 行、16 KiB、每行 2048 字符。长行片段可围绕原搜索条件的第一个非空命中读取，或按从 0 开始的 Unicode 字符偏移续读，默认 2048、最多 4096 字符，返回继续位置和匹配截断信息。本地单行扫描上限 16 MiB，超限会明确说明，不能据此认定未读取部分没有相关内容。工具详情不展示原始日志正文。

历史工具证据回放压缩为引用，原始本地会话保持不变；搜索每文件最多保留 100000 条命中，截断计数属于下界。每轮正文证据预算 128 KiB（包含预留的元数据开销），读取结果会返回剩余预算；最多 20 次模型请求，最后一次预留给无工具的结果总结。长会话按完整轮次裁剪发送上下文并显示提示，本地历史完整保留。

## Skills

预置 10 个功能入口，共享文件操作、搜索与分析、标记与高亮、导航定位四类工作指导。简单明确的操作直接依据工具定义执行；复杂任务按需读取相关指导，同轮避免重复加载相同工作流。关键词颜色标签仅应用已有标签，不创建新标签或任意整行颜色。

在配置弹窗的 Skills 页扫描 Codex、Claude、Cursor、.agents 的常见目录及环境变量指定目录，也可添加自选目录或单个 Skill 文件夹。支持共享安装中的 Skill 目录符号链接，规范化路径去重。新发现项默认关闭；目录和单项开关只选择是否提供指导，不禁用对应工具。单项可查看、启用、禁用、刷新或移除。启用项用于所有窗口、所有会话的后续分析，运行中的分析保持启动时快照。模型先获得摘要，按需读取正文和目录内 UTF-8 文本参考文件。单个文件最多 64 KiB；不执行脚本，拒绝绝对路径、越界路径及指向目录外的符号链接。未编辑的预置内容随版本升级，用户编辑、禁用及移除状态保留。

## MCP

配置弹窗的「MCP」页可添加本地 stdio 服务或 Streamable HTTP 服务。填写服务名称和连接 JSON；stdio 使用 `command`、`args`、`env`，HTTP 使用 `url`、`headers`。建议本地命令填写可执行文件的绝对路径，参数通过 `args` 数组传入。应用直接启动配置的程序，不隐式执行 Shell；进程工作目录为系统临时目录。服务继承应用进程环境，可用 `env` 覆盖；仅启用你信任的服务。

新增服务默认关闭。保存后用开关启用，后续分析可先列出服务、发现工具及其参数定义，再按请求调用。MCP 服务具有自己的资源访问范围，可能产生外部写入，不受内置日志工具的只读文件范围隔离。现阶段提供工具调用，不提供 MCP 资源、提示词、OAuth 登录或旧版 HTTP+SSE 双端点传输；HTTP 认证可配置请求头。

「测试连接」会启动本地服务或连接远程地址，完成初始化并显示工具名称，不执行工具；可停止测试，关闭配置或窗口也会取消测试。配置支持编辑和移除，运行中的分析保留启动时的服务快照。每轮连接独立持有，失败及超时不会自动重试；外部写入的完成状态可能未知，应先查询状态再决定后续操作。工具发现每服务最多 256 项，分页向模型返回；结果限制为 64 KiB，超限会明确提示操作可能已经完成。

## Memory

「记忆」页管理本机跨会话记忆，支持新增、查看、编辑、删除和刷新。默认开启对话使用，默认关闭自动保存；你可以在对话中明确要求“记住”，或开启自动保存，让 AI 按需提炼长期有用的偏好和事实。删除记忆须明确提出。模型通过检索工具按需读取相关记忆，读取到的内容会发送到当前模型服务；记忆仅是背景信息，不能代替当前日志证据或授予额外权限。

记忆保存在本地状态数据库，与会话独立。最多 200 条，每条标题最多 120 字符、正文最多 4096 字符。关闭对话使用不会删除记录，仍可在设置中手工管理；删除记忆不会改写既有聊天记录。保存和删除检查记录版本，冲突时保留编辑草稿，取消编辑后刷新再修改。成功的修改会刷新其他窗口；配置开关使用现有跨窗口同步机制，运行中关闭记忆后，后续记忆工具会被拒绝。

## 提示词与 RULES

在「提示词与 RULES」页编辑默认 AIAgent，导入 RULES，或新增自定义提示词。名称与正文在弹窗内编辑并保存，每项可独立启用；下次分析按列表顺序加载启用内容。应用范围和预算由宿主约束，工具定义描述可执行操作，AIAgent 负责分析与输出策略，RULES 提供用户约束，Skills 提供任务工作指导。内容保存在应用配置目录下的 `ai/prompts/` Markdown 文件中，也可从界面打开目录。单项上限 32 KiB、启用内容合计上限 48 KiB；缺失或损坏会提示错误。初始化补齐默认文件；通过已知默认内容基准更新未编辑副本，保留用户修改。

## 本地保存与边界

模型配置、API Key 和 MCP 连接配置保存在应用数据目录的独立 `ai/settings.json` 中，采用原子替换；Unix 目录权限为 0700、文件权限为 0600。密钥按本地明文方案保存；模型 API Key 输入默认遮罩，MCP JSON 编辑器显示完整配置。连接配置本身不发送给模型，已配置的模型密钥和 MCP 环境变量、认证头值会从工具输出中脱敏。会话保存在本地数据库独立表，记录模型引用、技能选择、消息和工具结果；重启时未完成分析显示为中断，不重放工具。

模型请求发往用户配置的模型服务，相关工具结果用于该轮分析。内置日志工具保持源日志只读；显式启用的 MCP 服务可提供额外外部能力。应用不允许模型创建 MCP 配置或绕过已禁用的服务，不提供通用 Shell 工具；本地过滤器读取不会登录或修改云端配置。

自动化验证使用本地模拟协议服务、临时日志及 GPUI 测试平台；真实模型服务兼容性、原生窗口布局和中文输入法交互仍需实际环境验收。

流式会话会显示等待模型响应、模型思考、生成回复、接收工具参数和执行工具等阶段。模型实际返回的思考内容与回复分别标示，保存在本地会话中；工具调用后的模型请求保留协议需要的推理内容及签名。服务返回空回复、非流式响应或输出长度不足时显示具体错误，结构化服务错误会在去除密钥后显示。连接测试仅验证基础生成，成功提示不代表日志工具已验证。准备会话时也可停止；取消后的任务不会发起模型请求。

已选搜索目录被删除、移动、卸载，或路径实际指向普通文件时，不会阻止发送消息。本轮仍可聊天并分析已打开的日志，面板提示目录不可用；目录搜索保持禁用，不会自动切换到其他路径。重新选择目录并发送新消息后，新的分析轮次才获得该目录访问范围。

MCP 与 Memory 扩展目前完成格式、差异、无依赖展开的 Cargo 元数据和架构静态检查，尚未执行编译、协议联调或真实窗口验收。
