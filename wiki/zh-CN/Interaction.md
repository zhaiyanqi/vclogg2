## 选择、复制与导航

| 操作 | 行为 |
| --- | --- |
| 点击日志行 | 激活该阅读区域和源行；结果行可联动正文定位 |
| 双击文字 | 按当前词边界设置选词 |
| 三击 | 选择所属日志行 |
| 同一逻辑行内拖动 | 选择文字；自动换行不把一条源行拆为多个业务行 |
| 拖入第二条源行 | 转为整行选择；拖回起始行可恢复文字端点 |
| Shift + 导航键 | 从锚点扩展连续行选择 |
| Ctrl/⌘+C | 优先复制有效文字选择，否则复制所选日志行 |
| Ctrl/⌘+Shift+C | 复制选中行并附带源行号 |
| 右键日志行 | 打开上下文菜单，可复制、标记、着色、添加注释、限制搜索范围 |

正文、当前结果和全局结果保留各自的焦点、选择与视口。重新搜索或折叠分组时以文档和源行身份恢复，不把可见行序号当成文件行号。失效结果和内容变化会使对应选区失效；折叠分组保留选择信息，隐藏期间不复制隐藏文字。

## 滚动与跟随

普通滚轮按设置使用像素倍率或逻辑行数。Ctrl + 滚轮调整日志字号；换行时可使用独立的按行滚动选项。横向滚动条位于日志行区域之外，不覆盖正文。

“末尾跟随”只决定刷新后是否滚到末尾。向上浏览或主动定位旧行可能关闭跟随；要恢复实时尾部阅读，重新启用。当前文件刷新不等于所有后台标签都刷新，详见[动态日志](Live-Logs.md)。

## 标签与多窗口

拖动标签可改变顺序。标签右键菜单提供关闭左右/其他/全部标签、路径复制、所在目录、标题重命名，以及复制/移动到新窗口或另一窗口。跨窗口拖放支持移动，按主修饰键可复制。

移动先在目标窗口准备文件，目标安装成功且源状态未变化才关闭源标签；失败保留源标签，传输期间源状态变化时可能保留两边副本。每个窗口有独立工作区，同一进程共享持久状态和应用设置。

再次启动不带路径时创建新窗口，带路径时转交到最近激活的窗口。最后一个窗口关闭后保存会话并退出，不常驻托盘。

## 设置窗口与编辑对话框

设置在独立窗口中打开，快捷键可再次关闭；高亮与历史管理进入同一窗口。设置使用草稿与预览，保存提交配置，取消撤回对应未提交的预览。文本输入拥有自己的编辑快捷键，避免单字母日志命令打断输入；快捷键录入框专门捕获组合键。Esc/Tab 继续用于退出与焦点导航。

过滤器勾选会更新查询草稿并保持弹层打开，添加正则过滤器时可自动开启正则；删除该项不会擅自关闭正则。文字标记必须通过按钮确认提交，失焦和滚轮不提交草稿。独立的历史删除操作一旦保存，不会因取消外层编辑而撤销。

## 文件操作边界

关闭标签、清除历史、清空收藏不会删除源日志。结果“保存…”是显式导出；应用自有临时结果可以从历史管理入口移到系统废纸篓，其他窗口仍打开的临时结果会受到保护。
