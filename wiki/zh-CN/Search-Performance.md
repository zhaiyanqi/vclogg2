# 搜索性能与验证

[English](../en/Search-Performance.md) · [Home / 首页](Home.md)

core 使用位置读取、行索引、压缩源行集合和并行匹配。稀疏目录结果保留命中偏移，密集投影可共享完整源索引。任务调度有界，取消后不再领取新任务；缓存写入不阻塞结果发布。

重复查询缓存为进程内 LRU，最多 16 项、查询文本与压缩结果合计 8 MiB。键包含源身份/内容、编码和查询选项。复用仍校验源文件，缓存命中不保证零磁盘 I/O；取消或失效快照不能作为成功缓存。

非 UTF-8 搜索采用有界解码批次，UTF-8 可借用原字节切片。结果上限保持源顺序，并多读取一个命中判断截断；并行完成顺序不能决定“前 N 条”。普通界面搜索完成后统一发布，不展示临时进度结果。

性能受文件大小、行数/行长、编码、存储、命中密度和并行度影响。快速刷新漏检中部改写的边界见[动态日志](Live-Logs.md)。

现有覆盖位于 `crates/vclogg-core/tests/`、core 文档测试和 workspace 能力测试。旧计时与测试数量保留在[归档](Archive.md)。本次迁移未重跑应用基准或测试，不将旧计时当作当前测量。
