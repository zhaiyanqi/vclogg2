# 常见问题与排障

[English](../en/Troubleshooting.md) · [指南首页](Home.md)

## 找不到搜索结果

先用一份结果已知的文件定位问题。打开[五行示例](../en/examples/checkout.txt)，选择 **当前**，按 **Ctrl+F / ⌘F** 聚焦主搜索框，关闭正则，输入 `id=42` 并按 **Enter**。选择 **仅匹配**。搜索范围覆盖整份文件、结果上限为 0 时，源行号应为 **1 到 5**。

| 你实际看到什么？ | 下一步查哪里 |
| --- | --- |
| 还是上一条查询的结果 | 看主查询框是否已经提交、是否提示正则有误。新搜索排队或运行期间可以继续读上一份结果。 |
| 结果是空的，或者只剩几行带圆点的记录 | 切到 **仅匹配**，确认查询前后没有多余空格。空查询不会列出全文。若打开了页内查找，按 Esc 关闭，再用主搜索框提交。 |
| 恰好只有第 2、3、4 行 | 在正文右键选 **清除搜索限制**，重新提交。[起止行对照](Search-and-Filters.md#只查故障前后的几行) |
| 每份文件都只出现最前面的几条 | 查看 **设置 → 搜索** 中的每文件命中上限。要看完整结果，把上限调为 **0**，重新提交。 |
| 示例能查到，实际排查却缺了一份日志 | **全局** 只查参与的文件。**目录** 要核对路径、后缀和子目录选项。用两份服务样例复查，每份应有两条命中。[目录搜索练习](Search-and-Filters.md#在磁盘目录里找同一笔请求) |

主搜索在普通模式下把 `retry|timeout` 当作两个候选词。页内查找在普通模式下会连同竖线一起找，所以同样的文字可能没有命中。

## 日志在写入，界面没有跟随

确认窗口处于前台，日志是当前标签且完整索引已就绪，再确认末尾跟随是否开启。关闭跟随只停止滚到末尾；后台窗口和其他标签本来就不持续监测。

系统通知、400 ms 合并、正在进行的搜索、索引和画面准备都会增加延迟。网络盘可能依赖 30 秒复核；失败重试也有等待。怀疑中部改写未检测时按 F5 完整重建，详见[动态日志](Live-Logs.md)。

## 乱码、Binary 或换行不符合预期

查看编码菜单中的检测结果，尝试“重新检测并加载”。Binary 模式按每行 16 字节展示十六进制。报告问题时说明文件原编码、BOM、换行形式，并提供脱敏字节样本；当前菜单没有任意手工选择编码的列表。

## 快捷键不生效

先离开输入框并点击目标日志区域。检查设置中的自定义绑定和冲突，核对 macOS 主修饰键、功能键与 Fn 映射。M 操作行标记，N 需要单条源行，W 切换换行。完整默认值见[快捷键](Keyboard-Shortcuts.md)。

## 设置没有保存

查看设置窗口的错误提示，先解决无效值或快捷键冲突。有效修改会自动保存；如果写入失败，可以点 **重试**。[设置指南](Settings.md)

## 新构建看起来没有变化

核对“关于”中的版本和构建时间，以及实际正在运行的程序路径。同一数据根的单实例路由会把后续启动交给已有进程；已有安装版仍在运行时，新的命令行启动可能只是打开了它的新窗口。退出已有程序后再启动目标构建。

## 构建失败

确认使用 Rust stable、正确平台工具链、仓库根目录和锁文件。Windows 检查 MSVC/SDK；macOS 检查完整 Xcode 选择；Linux 核对原生开发库。Git 依赖下载失败时先确认网络，不要直接删除 Cargo.lock 来规避错误。[源码构建](Building.md)提供命令。

## 安装或系统安全提示

从项目 Releases 获取正确平台包。当前 macOS 构建无 Developer ID 公证，Windows 是否签名取决于发布配置。文件名没有 unsigned 标识也不能证明已经签名；按系统提供的包来源与签名信息核对，不要关闭系统安全保护来替代验证。

## 云端过滤器不可用

核对服务地址与 `/api/v1` 兼容性、网络和会话。旧服务器缺少分支能力时写入口禁用；离线缓存只包含以前浏览过的公开页面。远程冲突需要明确处理，不应通过反复提交覆盖，见[云端过滤器](Cloud-Filters.md)。

## 启动、历史记录或编辑遇阻

| 现象 | 可以怎么做 |
| --- | --- |
| Windows 启动提示数据目录错误 | 核对程序旁的 `vclogg2-data-dir.txt`。指定路径必须是可写的绝对路径。[数据目录](Data-and-Privacy.md) |
| 一条历史记录删不掉 | 检查该文件是否仍打开、已固定或有标记、注释。这些状态会保护历史记录。[历史与存储](Settings.md) |
| 编辑时拒绝保存 | 如文件已被其他程序修改，先复制要保留的改动，再重新打开磁盘上的文件。遇到编码提示，可将文字另存到新建的 UTF-8 文件。[编辑与保存](Editing.md) |

## 性能与诊断材料

大文件性能同时受行长、编码、命中密度、换行、磁盘与 GPU 影响。先记录文件大小/行数、编码、是否换行、搜索范围与上限、操作步骤和耗时，不使用单一历史基准推断本机结果。

从 **设置 → 高级** 选择应用日志等级，或导出诊断日志。需要分析操作耗时，可以录制性能 trace。[录制与源码说明](Architecture.md) · [历史性能记录](Archive.md)

## 提交有效 Issue

写明程序版本、系统和架构、文件大小和编码、操作步骤，以及哪一步与预期不同。比如「用五行样例搜 `id=42`，范围为当前，上限为 0，已清除行限制；预期第 1–5 行，实际只有第 1 行」。请把例子中的条件和行号换成你的实际情况。附件使用脱敏样本；状态库、云端会话、Cookie、CSRF 和签名材料可能含私密信息。[提交 GitHub Issue](https://github.com/zhaiyanqi/vclogg2/issues)

## 检查更新时打开了浏览器

检查更新每次优先联网。失败时显示有效缓存、连接失败及上次成功检查时间，不能据此确认已是最新；无有效缓存时打开 Releases。可再次检查重试，不受旧缓存期限或退避限制。如果浏览器也无法访问，请检查网络、DNS、代理和证书配置。
