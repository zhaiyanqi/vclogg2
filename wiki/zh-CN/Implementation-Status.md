# 实现状态

[English](../en/Implementation-Status.md) · [Home / 首页](Home.md)

本页汇总[使用指南](Home.md)所述功能的源码实现与适用范围。

| 领域 | 当前行为与边界 |
| --- | --- |
| 大日志 | 索引与虚拟读取；内存和延迟仍受行数、编码、单行长度影响 |
| 搜索 | 当前文件、选定已打开文件、目录快照；独立搜索标签，完成后统一发布 |
| 动态刷新 | 仅前台窗口当前 Ready 文档；首尾采样存在已说明的边界 |
| 编辑 | 显式完整文本编辑，不设固定文件大小限制，保存检查磁盘大小与时间 |
| 设置 | 进程内共用一个设置窗口，有效设置跨窗口生效并自动保存 |
| 持久化 | SQLite schema v23，按修订合并会话 |
| 云端 | UUID/修订合并与缓存浏览；需核对桌面/服务端鉴权兼容性 |
| 更新 | 手动检查优先联网；失败回退有效缓存，显示连接失败与上次成功时间，不用缓存确认已是最新；无有效缓存时打开 Releases；不自动下载安装 |
| 已移除 | AI 分析、MCP 和记忆模块。当前左侧栏可以显示文件树或垂直标签。 |
| 文档 | 主仓库双语 Markdown、mdBook，与官网合并 Pages 产物 |

手动检查场景见[UI 验收](UI-Acceptance.md)和[过滤器验收](Filter-Branch-Acceptance.md)。[归档](Archive.md)中的历史结果不等于当前测试结果。
