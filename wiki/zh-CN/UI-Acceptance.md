# UI 验收清单

[English](../en/UI-Acceptance.md) · [Home / 首页](Home.md)

以下是手动检查场景，**不是本次文档迁移执行的验收结果**。

- 打开空文件、小文件、大文件和超长行日志，检查可见行读取、换行、字体变化与源行跳转。
- 检查当前/全局/目录搜索标签、排队/取消、排序、行边界与结果定位。
- 复制文字/行、多选、标记、着色、添加/编辑/拖动文字标记，确认导出不混入装饰。
- 前台文件追加、截断、轮转，刷新中切换标签/窗口，检查跟随与 F5 恢复。
- 跨窗口预览设置、取消、保存、重开，检查唯一窗口、尺寸恢复与分类定位。
- 编辑支持的小文件、拒绝已变化源文件、取消脏草稿，新文件保存不覆盖已有目标。
- 检查平台快捷键、输入焦点、窗口按钮、高 DPI 和两种界面语言。
- 验证跨窗口复制/移动、会话恢复、受保护历史清理和临时结果归属。

单独记录源码提交、平台、场景和实际结果。旧验收预览板与结论保留在[归档](Archive.md)。
