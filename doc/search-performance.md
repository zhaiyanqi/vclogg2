# 搜索性能优化与验证

## 目录搜索调度与缓存写入

文件准备线程通过原子游标动态领取路径，保持最多四个工作线程和最终输入顺序；取消后不再领取待处理文件。目录扫描完成后的索引缓存由独立单线程写入，队列最多保留两个待写索引，队列满或创建线程失败时跳过可重建的缓存，搜索结果不等待磁盘同步。正在写入的缓存允许完成，取消的待写任务跳过。

验证：阻塞首个文件时其他线程仍能领取其后续路径；阻塞缓存写入时队列保持两项上限且提交不等待；保留顺序与取消回归。

## 密集结果投影

命中超过完整源文件一半行时共享原始行索引和压缩行号，通过源行选择读取；稀疏结果仍仅保留命中的起止偏移，并直接构造压缩集合，去除临时原生行号数组。投影与嵌套投影保留源行坐标、BOM 和末尾空行语义。

验证：密集投影的索引及压缩结果与原值共享同一 Arc；搜索、缺失行、末尾空行及嵌套稀疏投影回归。

## 联合索引搜索的超长行

每个块先检查是否拥有行起点，无行起点的中间块不补读行尾；恰好以 CR 或 LF 结束的块也不额外读取下一行。跨块行只由拥有其起点的块补读与匹配，索引和完整性摘要仍覆盖全部源块。

验证：跨六块长行的四个中间块缓冲均保持单块大小；联合搜索与普通搜索在 CR、LF、跨块 CRLF、末尾空行上的结果一致。

## 重复查询缓存

当前文件、全局与目录搜索共用进程内 LRU，最多 16 项，压缩结果及查询文本合计最多 8 MiB，不保留文档索引或源句柄。键包含路径、完整内容摘要、编码、文件大小及全部查询选项；仅缓存完整且已验证的快照。目录已有候选时先加载索引再验证缓存，未命中时仍走联合索引搜索。

缓存复用前后检查路径变化；没有强变更令牌的平台重新读取并校验源块，忽略可见行热缓存。取消、替换、截断和改写不会把过期缓存当作完成结果。Unix 上节省的是匹配与结果构建，仍有校验 I/O。

验证：同内容重开复用结果 Arc；可见块已缓存后改写仍拒绝旧结果；查询选项、数量上限、取消、LRU 淘汰与容量上限回归。
