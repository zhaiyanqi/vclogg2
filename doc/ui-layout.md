# VCLogg2 UI 布局层级

本文档是当前 GPUI 界面层级、稳定控件编号与实际控件类的可读合同。新增、删除、移动、重命名或替换控件类时，必须在同一提交内同步更新。

布局树中的每一行固定使用 `控件名 [编号] - 控件类`；重复方式、显示条件、交互行为与功能说明统一放在树下的“控件备注”中。`Button` 等语义控件来自 gpui-component，`BaseButton` 来自 gpui-base，`Div`、`Canvas`、`UniformList` 等来自 GPUI，`VirtualLogList` 与 retained surface 是项目自有控件。`Div` 统一表示由 `div()`、`h_flex()` 或 `v_flex()` 构造的 GPUI 容器。

## 渲染实体与源码映射

- [`main.rs`](../crates/vclogg-app/src/main.rs) 为每个原生窗口创建一个 `Workspace` 实体，并以 `Root::new(workspace, ...)` 安装 gpui-component 的窗口根。
- [`workspace.rs`](../crates/vclogg-app/src/workspace.rs) 的 `Workspace::render` 只负责顶层组合顺序：标题栏、文件工具栏、标签栏、活动标签内容、独立状态栏 surface、拖放观察/反馈、前景事件隔离和 Root 弹层。`WorkspaceStatusSurface`、正文 `LogRegionSurface` 与共享结果 `LogRegionSurface` 是独立 retained 实体，局部状态变化不要求重绘整个 Workspace。
- [`workspace/render_shell.rs`](../crates/vclogg-app/src/workspace/render_shell.rs) 负责标题栏菜单、文件工具栏、标签栏、共享搜索栏、搜索范围/补全弹层和新标签页的文件清单。TabBar 的“所有标签”是固定 suffix；“新建标签页”属于可滚动轨道的末端空白区。
- [`workspace/log_presentation.rs`](../crates/vclogg-app/src/workspace/log_presentation.rs) 负责 `DocumentSplit`、两个可调面板、正文/结果命中容器、统一 VirtualLogList 的固定行高与自动换行稀疏模式、滚动条、页内查找挂载点与状态栏内容。`search_results_viewer` 只有一个 surface：当前文件、全部打开文件与目录范围根据 `SearchScope` 切换投影，不各自持有结果面板实体。
- [`workspace/preferences.rs`](../crates/vclogg-app/src/workspace/preferences.rs) 负责搜索面板拖动事件层以及设置、历史、颜色标签、预定义过滤器等 Dialog 的打开和尺寸；各 Dialog 的内部布局继续由对应的 `*_dialog.rs` 持有。
- [`dialog_focus.rs`](../crates/vclogg-app/src/dialog_focus.rs) 为确认、取消按钮提供稳定动作派发节点；焦点句柄按动作 ID 保留在窗口 keyed state 中，重绘沿用同一焦点身份，卸载后由窗口释放，不增加布局节点或改变按钮编号。

## 键盘路径

- `Ctrl+O`（可在设置中修改）→ 同步注册不执行文件 I/O 的稳定“打开中”标签 → 最多 1 MiB / 200 行的有界安全预览 → 在同一稳定标签、表格与虚拟列表实体中原子换入完整索引。若严格强身份校验通过且会话保存了源行，预览会直接读取该行前后约 200 行并保持全局行号；否则安全回退文件头。预览阶段保留正文浏览、选择与复制，搜索、页内查找、按行定位、文件末尾和末尾跟随会等到完整索引就绪；打开中或预览标签被关闭后，迟到的预览与完整结果都按路径和文档 ID 丢弃，不会重新打开标签。完整索引失败时保留安全预览并允许重新加载。会话中位于预览范围外的选择与标记作为待恢复领域行保留，完整文档到达后再合并；预览内的新用户选择优先于旧锚点。
- 进程命令行中位于可执行文件之后的每个路径按原顺序转换为初始文档，并在首个 Workspace 的状态库 bootstrap 后进入与 `Ctrl+O` 相同的空壳、预览与完整索引链路；命令行路径不构造默认覆盖，因此会恢复已有会话。文件关联或终端启动不维护第二套加载状态。
- 预定义过滤器弹层只把匹配值作为完整 `|` 分隔段加入或移除，不会因普通子串相同误判选中；正则匹配值中的 `|` 仍作为过滤器内容整体参与边界判断。搜索执行层可精确避免重复查询段，但实体列表只按 UUID 识别身份：名称、内容、类型、备注与共创状态全部相同的不同 UUID 仍完整展示、保存与同步。Checkbox 动作立即更新当前范围的查询草稿并保持弹层开启，正则项只在加入时自动开启正则，不会在移除后擅自关闭用户的正则模式；`Esc` 或外部点击关闭弹层并把焦点还给触发器。过滤器管理的第一层与第二层弹窗统一使用原生 DialogTitle；本地详情、云端只读详情、首次分享和 A467 冲突处理共用单一二级路由与 Dialog surface，任何时刻只有一个二级页面。`Esc` 只关闭最上层弹窗并由 Root 恢复原触发焦点，不关闭外层对话框。保存编辑器后 SQLite 顺序与所有窗口的弹层一次同步，取消外层对话框不会改变已提交集合。
- 云端过滤器页在已有凭据会话时首次进入会自动加载目录；搜索、排序和翻页各自产生新的一页快照。每个在线分页会按标准化服务器地址隔离写入公开目录缓存，不保存 Cookie、CSRF 或身份凭据；服务不可达时 A238 汇总此前已浏览分页并在本机完成搜索、排序和分页。离线目录只允许把严格晚于共同基线的缓存修订下载或安全合入本地，不得回退基线；点赞、首次分享、提交、删除和修订读取/恢复保持禁用。批量下载先应用新分支、快进与无冲突三方合并，再顺序呈现字段冲突；“稍后处理”保持对应本地分支不变。合并后的本地内容不会自动提交。在线提交使用跟踪引用中的 `baseRevision`；结构化修订冲突只触发刷新与三方合并，不通过错误文本判断，也不自动重试。服务器未声明 `filter-uuid-branches-v1` 时目录浏览、缓存和下载仍可用，首次分享与远程提交明确禁用并提示升级。
- 主窗口不执行启动或后台版本检测，也不下载、暂存或安装发行包。A355 在所有构建配置下直接通过系统浏览器打开 `https://github.com/zhaiyanqi/vclogg2/releases`；A403 使用 `关于 ver.<当前版本>` / `About ver.<current version>` 文案，并继续打开设置对话框的“关于”分类。
- 文件历史打开时同时扫描系统临时目录下的 VCLogg2 搜索结果。普通文件记录与临时结果共用筛选输入但各有一个固定高度滚动列表；临时结果不进入 SQLite Session、最近文件或恢复集合。删除前从所有已注册 Workspace 汇总打开路径，任何窗口仍持有的临时结果都会禁用；确认后逐个调用当前平台系统废纸篓，成功项再尝试移除已空的直属临时目录。
- Windows Release 是不写入 ProgID、`RegisteredApplications`/Capabilities 或 `OpenWithProgids` 的纯便携包；macOS bundle 通过 `Info.plist` 声明文档类型，Linux 安装器在当前用户范围写入 `.desktop`、图标与 MIME 列表。终端和系统文件打开事件传入的一个或多个路径继续复用单实例与普通打开链路。
- “视图”菜单在打开时按当前窗口状态提供“进入全屏 / Enter full screen”或“退出全屏 / Exit full screen”；macOS 可用标准 `⌃⌘F` 或兼容的 `F11`，Windows/Linux 使用 `F11`，均只切换当前窗口的平台全屏状态。macOS 窗口模式为原生三色窗口按钮保留约 80px 外层起始间距；全屏后系统隐藏三色按钮，TitleBar 外层占位归零，组件内部仍保留约 12px 紧凑边距。
- `Ctrl+Shift+N` 或“新窗口”创建新的原生窗口并立即激活；每个窗口独立拥有标签、活动文件、搜索、历史弹层和通知状态。正常关闭单个窗口会把它移出恢复集合；整应用退出时按窗口创建顺序收集仍存活窗口，路径去重后用一次事务保存文件会话、标签并集和首个有效活动标签，下一次启动的“上一次文件”可恢复跨窗口集合。
- 标签菜单“复制到新窗口”在点击提交点捕获路径、自定义标题、源行位置、查询选项、结果模式、标记和呈现设置。新窗口完成状态库 bootstrap 后用该快照重新索引并一次恢复标签；源窗口标签、选择和搜索不变，临时结果标签继续保持不进入最近文件或恢复清单的边界。
- “移动到新窗口”复用同一不可变传输快照，但只在目标文件成功建立索引且源标签当前会话仍与点击时完全一致时关闭源标签。目标失败时明确保留源标签；传输期间源行、查询、标记、显示选项或名称发生变化时，目标保留已打开副本并提示源标签因变化而保留。重复移动同一标签会被阻止。
- “移动/复制到另一窗口”由应用级窗口注册表选择最近获得焦点的其他原生窗口。目标通过自己的 Workspace 接收并重新索引传输快照；目标正在打开文件、已经打开同一路径或已关闭时会给出明确反馈。移动仍遵守 A142 的成功确认与源快照一致性检查，立即拒绝通过延迟回执完成，避免窗口间嵌套更新。
