# 功能实现状态

本文档记录当前 Rust + GPUI Component 应用的功能范围与实现状态。状态只描述当前仓库；“后续”不表示能力被取消。

## 状态定义

- **已完成**：主路径已经落到 Rust/GPUI 实现，并通过工作区静态检查。
- **进行中**：基础结构已经存在，但完整产品语义尚未覆盖。
- **后续**：尚未进入实现，仍属于规划范围。

## 阶段顺序

1. 完成本地日志闭环：可取消搜索、文件追加/重新加载、视口与多选、标记和高亮。
2. 引入持久状态库：最近文件、会话恢复、收藏、设置和索引缓存。
3. 完成多文件高级工作流：全局搜索、导出、拖放、标签菜单与多窗口。
4. 接回扩展服务：预定义/云端过滤器、三平台分发与更新。

任何能力只有在本表更新为“已完成”并同步对应交付说明后，才算正式交付。
