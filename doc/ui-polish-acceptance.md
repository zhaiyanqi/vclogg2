# VCLogg2 界面优化验收说明

本次优化覆盖应用主题配色、控件字号与间距、默认 10 色标签、选中/悬停/聚焦/高亮状态，以及文件拖入和搜索候选弹层的动效。实现遵循 GPUI Component 的语义主题与桌面交互约定。

## 可视化产物

- [界面优化验收板](assets/ui-polish-acceptance.svg) — 同时展示浅色/深色状态、搜索高亮层级、默认 10 色标签、排版尺度、间距尺度与动效参数。
- 该验收板是代码中实际色值与参数的规格预览，不是真实窗口截图。

## 实现规格

### 主题与交互状态

界面表面采用玻璃材质风格。GPUI 没有元素级背景模糊，因此下表记录按 `c = fg * a + bg * (1 - a)` 逐层合成后的不透明结果（浅色底 `#f0f1f2`、深色底 `#0f1425`）。

| 项目 | 晨雾浅色 | 深海夜色 | 验收重点 |
| --- | --- | --- | --- |
| 应用背景 | `#eeeef0` | `#0b1020` | 长时间阅读时保持安静，不与日志内容争夺注意力 |
| 窗口材质（标题栏/工具栏/标签栏/状态栏） | `#f7f7f6` | `#111827` | 三行顶栏与状态栏是同一层材质，比应用背景高一档 |
| 控件材质（路径栏/活动标签/Kbd） | `#fcfcfb` | `#1f283a` | 比窗口材质再高一档，配合边框与阴影读作抬起 |
| 日志表面 | `#fbfaf8` | `#171d2a` | 正文区域自身的底色 |
| 主强调色 | `#2563eb` | `#8b8cff` | 主按钮、焦点环、选中边界保持同一语义 |
| 边框 / 强边框 | `#d0d3d7` / `#bdc0c6` | `#283043` / `#394156` | 玻璃边缘高光在无模糊环境下不够清晰，结构边框统一使用明确的边框色 |
| 行悬停 | `#f0f3f8` | `#212d41` | 比静止态轻，比选中态弱 |
| 行选中 | `#dce9ff` + `#7db7e8` 边界 | `#263f68` + `#4f87c7` 边界 | 持久显示，不能与悬停混淆 |
| 文本选区 | 主色 26% | 主色 34% | 字符仍清晰可读 |
| 普通搜索命中 | `#c8efa8` 底 + `#10200d` 字 | `#3b6732` 底 + `#eff9e8` 字 | 实色绿底深字，不是半透明黄 |
| 页内查找命中 | `#f4c542` 底 + `#201a06` 字 | 同浅色 | 当前定位结果最醒目，两个主题共用同一金色 |
| 行号 | `#747c88` / 底 `#f1f0ed` | `#8290a6` / 底 `#192231` | 字号为 `clamp(8px, 日志字号 - 2px, 18px)` |
| 标记圆点 | 命中 `#e74856`/描边 `#d83b01`；标记 `#f5b942`/描边 `#8a5a00`；空态描边 `#858c98` | 空态描边 `#8794aa`，其余同浅色 | 同时命中且标记时用 135° 双色渐变 |
| 状态圆点 | 空闲 `#31b46d` + 12% 光晕 | 同浅色 | 忙碌时切换为主强调色与 `--accent-soft` 光晕 |

日志级别着色是整行实色底 + 最左侧 3px 色条：

| 级别 | 浅色底 | 深色底 | 色条 |
| --- | --- | --- | --- |
| ERROR | `#fff0f1` | `#3b2025` | `#d13438` |
| WARN | `#fff8e8` | `#3b321e` | `#e9a800` |
| INFO | `#eff7ff` | `#1c2b3d` | `#0f6cbd` |
| DEBUG | `#f5f6f8` | `#242832` | `#7a828d` |

深色主题为 ERROR、WARN、INFO 与 DEBUG 分别提供适配深色表面的行底色；INFO 与 DEBUG 按 ERROR/WARN 的同一明度关系设置，避免浅色背景在深色界面中过亮。

日志正文、当前结果和全局结果区域继续保留键盘焦点与快捷键上下文，但不在整个数据区域外围绘制焦点边框；活动行和行选中状态负责反馈当前位置。

### 已知组件约束

- `--ambient-background` 的两处径向光晕和三色标线性渐变无法用 GPUI 的两点 `linear_gradient()` 复刻，应用背景取纯色 `#eeeef0` / `#0b1020`。
- 活动标签指示层由 gpui-component 内部绘制，Large 档内芯固定为 28px；标签外框为 36px，保留组件规定的内芯留白。
- `PopupMenu` 不暴露圆角、内边距与项高，菜单弹层仍是组件默认外观。

### 默认颜色标签

新建状态库使用以下顺序：天蓝、琥珀、珊瑚、青瓷、草绿、金黄、紫藤、樱粉、青柠、靛紫。顺序仍决定“轮换颜色”的顺序。

已有状态库中的标签属于用户数据，本次不会覆盖其名称、颜色或顺序；需要查看新默认值时应使用全新的状态库进行验收。

### 字号与间距

- 应用界面 `rem` 基准为 15px；对话框与空状态继续使用语义字号档位。
- 主窗口的三行顶栏、搜索栏与状态栏使用固定像素，不随界面缩放联动：

| 栏位 | 尺寸 |
| --- | --- |
| 标题栏 / 菜单行 | 栏高 36px；菜单按钮 28px 高、11px 横向内边距、8px 圆角、12px 字 |
| 文件工具栏 | 栏高 44px；图标按钮 34px 见方、10px 圆角、按钮间距 3px；路径栏 36px 高、12px 圆角；file-meta 11px 字并以 `--divider-soft` 竖线分隔 |
| 标签栏 | 栏高 48px、5px 内边距、16px 圆角；标签 36px 高、158–320px 宽、12px 字；关闭按钮 7px 圆角 |
| 搜索工具栏 | 栏高 50px、6px 间距；模式下拉 110px；`Aa` 与 `.*` 各 34px 见方；输入框最小 180px；搜索按钮最小 88px；结果计数胶囊最小 68px、11px 字 |
| 搜索面板 | 展开高度下限 197px |
| 状态栏 | 栏高 30px、12px 横向内边距、11px 字 |

- 日志正文继续使用独立的等宽字体大小设置，不被界面基准字号覆盖；行高仍为“字号 + 行距”。
- 控件内间距小于控件间间距，控件组间距小于区段间距。

### 动画

- 文件拖入遮罩、跨窗口标签提示、搜索候选弹层：160ms，`ease-out`，透明度与约 8px 的同方向位移共同变化。
- 状态圆点脉冲：1s 循环、`ease-in-out`，透明度在 1.0 与 0.4 之间往返，只在打开文件、搜索或页内查找期间执行。
- 活动标签滑动指示层由 gpui-component 提供，使用 250ms 弹簧动画。
- 除状态圆点外，动画只在临时表面出现时执行，不循环、不弹跳，不阻塞输入。
- 搜索候选的键盘选中态在动画结束后持续可见。

## 真实窗口验收清单

项目规则要求真实窗口验收由用户明确启动，因此本次没有自动运行应用或抓取窗口截图。可使用仓库已有的调试脚本启动后逐项检查：

1. 分别切换“晨雾浅色”“深海夜色”和“跟随系统”，确认主按钮、普通按钮、标签页、侧栏、列表和表格使用一致语义色。
2. 在日志表格中依次检查静止、悬停、单行选中和多行连续选中，确认四种状态可区分。
3. 执行普通搜索，再打开页内查找，确认页内当前匹配明显强于普通搜索；拖选文字时确认文本选区不会盖住字符。
4. 使用新的状态库打开“高亮 → 颜色标签…”，确认默认 10 色顺序、名称和色块与验收板一致。
5. 在顶部文件带、搜索带和设置对话框中检查字号与控件高度；放大窗口或调整界面缩放时，文字、图标和间距应同步变化。
6. 用键盘进入正文、当前结果和全局结果区域，确认不会出现包围整个日志区的蓝色边框，方向键移动和选中行仍保持可识别；搜索候选使用上下方向键时，选中项应显示主色左边界。
7. 拖入日志文件并打开搜索候选，确认临时表面从触发方向快速减速进入，过程约 160ms 且操作不中断。
8. 逐项量测三行顶栏与状态栏高度是否为 36 / 44 / 48 / 30px，行号字号是否随日志字号变化并在 8–18px 之间夹取。
9. 打开“工具”菜单确认“设置”已收入其中，并逐个展开八个菜单检查新增项、分隔线与右侧快捷键提示。
10. 打开一个文件观察状态栏左侧圆点：空闲为绿色静止，打开或搜索期间切换为强调色并循环脉冲。
