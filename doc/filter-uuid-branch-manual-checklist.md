# 过滤器 UUID 分支手工验收清单

本清单用于发行前的人工界面核对。自动验证期间不启动真实 GPUI 窗口。

## 本地身份与迁移

- 新建两个名称、匹配值、正则、备注和共创状态完全相同的过滤器，确认列表同时保留，短 UUID 不同，详情可复制各自完整 UUID。
- 导出后确认文件版本为 v5；重新导入时，相同 UUID 不新增重复项，不同 UUID 的同内容项仍并存，当前文件未包含的本地项不被删除。
- 准备 v1–v4、数组和 Qt 格式样例：合法 UUID 保持不变；缺失或非法 UUID 只在首次迁移时生成，重启后稳定。

## 下载、更新与合并

- 下载未存在的云端过滤器，确认本地 UUID 与云端 UUID 相同，状态为“已同步”。
- 仅远端修改一个字段后执行“更新本地”，确认快进到远端内容。
- 本地与远端分别修改不同字段后执行“合并更新”，确认两边改动都保留；合并后状态为“本地有修改”，不会自动提交。
- 本地与远端修改同一字段为不同值，确认进入逐字段冲突页面；分别验证“全部保留本地”“全部采用远程”和逐项选择。
- 在冲突页选择“稍后处理”，确认对应本地内容和共同基线均不改变。
- 批量选择安全项和冲突项，确认安全项先应用，冲突按所选顺序逐个处理。

## 提交、分叉与并发

- 已同步分支本地修改后，从云端详情执行“提交本地修改”，确认同一 UUID 的修订递增；首次分享弹窗不再列出该分支。
- 制造服务端 409 修订冲突，确认客户端读取最新版并进入安全合并或冲突页面，不自动再次推送。
- 从只读云端详情执行“另存为新过滤器”，确认生成新 UUID、保留派生来源，并且可作为新分支首次分享。
- 从历史修订执行“恢复到本地”，确认远端未立即变化，本地成为待提交修改。
- 删除远端分享，确认本地过滤器仍在，只解除该服务器的跟踪引用。

## 兼容、离线与管理后台

- 连接未声明 `filter-uuid-branches-v1` 的旧服务器，确认仍可浏览、缓存和下载，但首次分享及远程提交禁用并提示升级。
- 离线加载缓存时，确认只能下载或合入高于本地基线的修订；较旧缓存和同修订不同内容不会覆盖本地或回退基线。
- 管理后台创建内容完全相同但 UUID 不同的过滤器，确认允许共存并显示 UUID；使用过期修订编辑仍返回冲突。
- 验证普通分享中同 UUID 被其他所有者占用时显示身份冲突，而非内容重复错误。

## 路由与焦点

- 本地详情、云端详情、首次分享和冲突处理之间任一时刻只显示一个二级页面，不叠加第三层冲突弹窗。
- 从列表按钮打开二级页面后，分别使用关闭按钮和 `Esc` 返回，确认焦点恢复到原触发控件。
