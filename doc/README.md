## 维护约定

- 功能范围变化时更新 `migration-status.md`，并在需要时同步 `feature-parity.md`。
- 模块职责、状态所有权或依赖方向变化时更新 `architecture.md`。
- 控件新增、删除、移动、重命名或层级变化时更新 `ui-layout.md`，保持控件编号稳定。
- 安装格式、签名、构建脚本或发布流程变化时更新 `delivery.md` 与项目首页中的常用命令。
- 一次性验收或阶段性交付记录应标明日期和验证边界，避免把静态检查描述成真实窗口或目标平台验证。
- 图片等配套材料放在 [`assets/`](assets/)；文档使用相对链接，确保 GitHub 和本地预览都可访问。
