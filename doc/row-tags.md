# 文字标记

日志行中的文字标记使用 Tag 控件。新增和双击修改共用一个弹窗，草稿由弹窗实体持有，只有“添加 / 保存”提交；取消或非拖动状态下的 Esc 丢弃草稿。标记保存在文件会话里，原始日志、搜索文本、复制和导出内容均不包含标记。

## 弹窗布局

默认宽度为 46rem，左侧是可滚动编辑表单和固定在底部的日志行预览，右侧是 14rem 的历史标记文字列表；底部沿用标准 DialogFooter。

```text
新增标记 / 编辑标记
┌──────────────────────────┬──────────────────┐
│ 文字                     │ 历史标记         │
│ [输入标记文字]           │ [搜索历史标记]   │
│                          │                  │
│ 文字大小    标记高度     │ 标记 A           │
│ [滑块+值]   [滑块+值]    │ ...虚拟列表      │
│ 当前行高与适配说明       │ 标记 B           │
│ 文字颜色    标记颜色     │ 标记 C           │
│ [取色器]    [取色器]     │                  │
│ 透明度 [滑块 + 百分比]   │                  │
│ □ 加粗      □ 胶囊圆角   │                  │
│                          │                  │
│ 日志行预览（固定底部）   │                  │
│ ● 42 源日志文字 [Tag]    │                  │
└──────────────────────────┴──────────────────┘
                            [取消] [添加 / 保存]
```

- 文字限制为 1–128 个字符，不能换行；空值显示表单错误。
- 新增标记默认沿用最近一次确认使用的字号、文字色、标记色、高度、透明度、加粗和圆角，文字输入与历史搜索框保持为空；没有历史时使用默认样式。样式随历史跨重启保留，取消草稿不改变下次默认值；编辑已有标记仍载入该标记自身的属性。
- 字号和高度使用与日志相同的逻辑像素。高度不超过当前基础行高，字号不超过高度减去上下边框；滑块联动维持约束。换行行的多行高度不扩大这个上限。
- 绘制时再次按所在视图的行高夹取，保证复用、字号变化或行距变化后仍不撑大日志行；存储的样式偏好不因暂时夹取而丢失。
- 文字色和背景色使用标准 ColorPicker，包含组件原有透明度能力；预览直接调用与日志行相同的 Tag 渲染函数。
- 整体透明度为 0–100%，0% 不透明、100% 完全透明，同时影响文字、背景和边框，并与取色器中的颜色 Alpha 叠加。透明度放在标记交互容器上，Tag 自带的悬停效果不会覆盖用户值。旧版标记缺少该属性时按 0% 读取；预览、日志行、历史复用和默认属性记忆使用相同值。
- 预览使用打开弹窗时已呈现的源行文字快照，不重新读取文件。字号、字体、基础行高、正文色和行号设置取自当前日志展示；标记列、行号和分隔线复用日志组件，正文使用与日志相同的 SelectableLogText，以被动预览模式绘制，不注册到窗口文字选择作用域。正文容器以基础行高垂直居中；Tag 复用 LogTagLayer 按预览行边界夹取位置。只显示一个基础日志行，长正文在预览边界裁切。
- 可在预览行内拖动标记，超过 GPUI 拖动阈值后开始；与实际日志共用拖动位置限制和空拖动视图，原 Tag 在行内移动。鼠标移出预览行时继续限制在行边界，松手只更新弹窗的临时展示位置。“添加 / 保存”仅提交文字和样式；已有标记保留原日志行中的位置，新增标记沿用最初右键的位置，预览拖动或夹取均不回写。拖动中按 Esc 或窗口失活取消本次拖动，回到拖动前位置；关闭弹窗丢弃临时展示位置。
- 表单滚动视口内部保留焦点外框边距；历史筛选框同样保留两侧空间，继续使用 Input 自带的边框和焦点样式。
- 默认维持紧凑的 85% 字号和主题圆角。加粗用于强调；胶囊圆角是额外的外形选项。
- 标记仍可在源行内拖动。编辑弹窗不会用 Input 替换行内 Tag，也不会因失焦、滚轮或退出而提交草稿。

## 新增与复用

右键日志行 → 文字标记 → 新增标记… / 最近使用的 10 个标记。最近项点击后直接添加并标记该源行；“新增标记…”打开完整弹窗，可搜索全部历史标记。右侧只显示标记文字，不展示颜色、字号或外形；点击后将完整文字和样式载入左侧表单及底部预览，再修改后添加。双击或右键“编辑标记…”复用同一个弹窗。

“新增标记…”下方提供“清除所有标记”，清除右键日志行所属文件的全部文字标记，包括当前未显示的行，并保存到文件会话。正文、当前文件结果和全局结果共用此入口；没有文字标记时禁用。操作保留行标记圆点、复用历史和其他文件的文字标记。

历史标记按文字完全一致去重，区分大小写，同名保留最近使用的样式，并按最近使用排列、跨重启保存；旧版重复历史在读取时同样去重。新记录以文字摘要为键更新，同名修改样式不会新增历史项。每次添加产生独立实例，修改当前实例不改动其他日志行。删除行内标记保留已有行标记和复用历史。

会话标记由 `DocumentTab.file` 拥有，弹窗由 Root 持有，Workspace 只保留弱引用和业务目标。复用历史由窗口注册表共享，SQLite `row_tag_presets` 独立保存；后台逐次写入并纳入关闭窗口 / 退出的等待队列。

## 参考与属性取舍

- [Trello 标签](https://support.atlassian.com/trello/docs/adding-labels-to-cards/)把选择已有标签与编辑名称、颜色放在相邻入口，适合借鉴其“先复用，再修改”的短路径。
- [Bluebeam Tool Chest](https://support.bluebeam.com/revu/features/tool-chest-guide.html)保存自定义标注以便再次使用，适合借鉴“文字和样式整体复用”的语义。
- 额外样式包括整体透明度、加粗和胶囊圆角，取色器保留颜色 Alpha。独立字体、边框粗细、图标、备注和分类会增加表单复杂度；当前日志注释任务不必增加这些属性。若后续出现大量标记整理需求，再考虑收藏和分类。

以上为交互设计与源码约束；编译和现有回归检查不能替代实际窗口中的布局、拖动、取色和焦点验收。
