# 日志标签

日志行只绘制 Tag。新增和双击修改共用一个弹窗，草稿由弹窗实体持有，只有“添加 / 保存”提交；取消或 Esc 丢弃草稿。标签保存在文件会话里，原始日志、搜索文本、复制和导出内容均不包含标签。

## 弹窗布局

默认宽度为 46rem，左侧是可滚动编辑表单和固定在底部的日志行预览，右侧是 14rem 的历史标签文字列表；底部沿用标准 DialogFooter。

```text
新增标签 / 编辑标签
┌──────────────────────────┬──────────────────┐
│ 文字                     │ 历史标签         │
│ [输入标签文字]           │ [搜索历史标签]   │
│                          │ 点击复用，再修改 │
│ 文字大小    标签高度     │ 标签 A           │
│ [滑块+值]   [滑块+值]    │ ...虚拟列表      │
│ 当前行高与适配说明       │ 标签 B           │
│ 文字颜色    标签颜色     │ 标签 C           │
│ [取色器]    [取色器]     │                  │
│ □ 加粗      □ 胶囊圆角   │                  │
│                          │                  │
│ 日志行预览（固定底部）   │                  │
│ ● 42 源日志文字 [Tag]    │                  │
└──────────────────────────┴──────────────────┘
                            [取消] [添加 / 保存]
```

- 文字限制为 1–128 个字符，不能换行；空值显示表单错误。
- 新增标签默认沿用最近一次确认使用的字号、文字色、标签色、高度、加粗和圆角，文字输入与历史搜索框保持为空；没有历史时使用默认样式。样式随历史跨重启保留，取消草稿不改变下次默认值；编辑已有标签仍载入该标签自身的属性。
- 字号和高度使用与日志相同的逻辑像素。高度不超过当前基础行高，字号不超过高度减去上下边框；滑块联动维持约束。换行行的多行高度不扩大这个上限。
- 绘制时再次按所在视图的行高夹取，保证复用、字号变化或行距变化后仍不撑大日志行；存储的样式偏好不因暂时夹取而丢失。
- 文字色和背景色使用标准 ColorPicker，包含组件原有透明度能力；预览直接调用与日志行相同的 Tag 渲染函数。
- 预览使用打开弹窗时已呈现的源行文字快照，不重新读取文件。字号、字体、基础行高、正文色和行号设置取自当前日志展示；标记列、行号和分隔线复用日志组件，Tag 复用 LogTagLayer 按预览行边界夹取位置。只显示一个基础日志行，长正文在预览边界裁切。
- 表单滚动视口内部保留焦点外框边距；历史筛选框同样保留两侧空间，继续使用 Input 自带的边框和焦点样式。
- 默认维持紧凑的 85% 字号和主题圆角。加粗用于强调；胶囊圆角是额外的外形选项。
- 标签仍可在源行内拖动。编辑弹窗不会用 Input 替换行内 Tag，也不会因失焦、滚轮或退出而提交草稿。

## 新增与复用

右键日志行 → 添加标签 → 新增标签… / 最近使用的 10 个标签。最近项点击后直接添加并标记该源行；“新增标签…”打开完整弹窗，可搜索全部历史标签。右侧只显示标签文字，不展示颜色、字号或外形；点击后将完整文字和样式载入左侧表单及底部预览，再修改后添加。双击或右键“编辑标签…”复用同一个弹窗。

历史标签按完整文字与样式去重、按最近使用排列并跨重启保存；旧版文件会话中的标签也可复用。每次添加产生独立实例，修改当前实例不改动其他日志行。调整历史样式后保存会记住这个新组合，原组合仍可复用。删除行内标签保留已有行标记和复用历史。

会话标签由 `DocumentTab.file` 拥有，弹窗由 Root 持有，Workspace 只保留弱引用和业务目标。复用历史由窗口注册表共享，SQLite `row_tag_presets` 独立保存；后台逐次写入并纳入关闭窗口 / 退出的等待队列。

## 参考与属性取舍

- [Trello 标签](https://support.atlassian.com/trello/docs/adding-labels-to-cards/)把选择已有标签与编辑名称、颜色放在相邻入口，适合借鉴其“先复用，再修改”的短路径。
- [Bluebeam Tool Chest](https://support.bluebeam.com/revu/features/tool-chest-guide.html)保存自定义标注以便再次使用，适合借鉴“文字和样式整体复用”的语义。
- 本次增加加粗和胶囊圆角，取色器保留透明度。独立字体、边框粗细、图标、备注和分类会增加表单复杂度；当前日志注释任务不必增加这些属性。若后续出现大量标签整理需求，再考虑收藏和分类。

以上为交互设计与源码约束；编译和现有回归检查不能替代实际窗口中的布局、拖动、取色和焦点验收。
